MOCHILAS S.O.S. - PROTOTIPO AMPLIADO
====================================

CONTENIDO
- index.html: aplicación web.
- styles.css: diseño adaptable en azul marino, azul claro, blanco y rojo.
- app.js: navegación, listas, progreso, familia, asistente guiado, mapa, sonido y ubicación.
- assets/logo-mochila-sos.png: logo original proporcionado para el proyecto.

CÓMO ABRIR
1. Extrae el ZIP.
2. Abre la carpeta Mochila_SOS_Renovada.
3. Abre index.html en un navegador.

PARA GITHUB PAGES
Sube el contenido de la carpeta Mochila_SOS_Renovada a tu repositorio. index.html debe quedar en la raíz publicada.

IMPORTANTE
- Las listas, el progreso, los datos familiares y el plan se guardan en el navegador de ese dispositivo.
- Las guías básicas y funciones locales pueden usarse una vez cargada la aplicación.
- Las imágenes externas, enlaces y alertas actualizadas requieren internet.
- El asistente incluido es un prototipo de respuestas guiadas sin conexión; una IA generativa real requiere conexión y un servicio de IA.
- El mapa es ilustrativo. No representa zonas oficiales verificadas ni debe usarse para decidir una evacuación real.
- La ubicación usa permisos del navegador; compartirla con otras personas requiere un medio de comunicación.
- El sonido solo se reproduce en el dispositivo y no contacta automáticamente a emergencias.
- La información médica es general y no reemplaza indicaciones de profesionales de salud o veterinarios.
